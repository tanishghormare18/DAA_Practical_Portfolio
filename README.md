# DAA Practical Portfolio

> **Design & Analysis of Algorithms — Practical Portfolio**
> **Course Code:** N-PCCCD501P | **Session:** 2026–27

A professional web-based portfolio developed to organize and present the practical work for the **Design & Analysis of Algorithms (DAA)** course.

The portfolio provides a structured and accessible way to explore algorithm implementations, practical problem statements, and supporting resources from a single interface.

---

## 📖 About the Course

The Design & Analysis of Algorithms course focuses on designing algorithms and analysing their **efficiency, correctness, time complexity, and space complexity**, while understanding different problem-solving techniques for efficient algorithm design.

The practical curriculum covers searching, sorting, graph algorithms, dynamic programming, divide-and-conquer, backtracking, and algorithmic complexity analysis.

## 🚀 Getting Started

### Prerequisites

No backend or database is required.

You only need:

* Git
* A modern web browser
* Optional: Visual Studio Code with Live Server

### Clone the Repository

```bash
git clone https://github.com/tanishghormare18/DAA_Practical_Portfolio
```

### Navigate to the Project

```bash
cd DAA-Practical-Portfolio
```

### Run Locally

Open `index.html` directly in your browser.

For development, you can use **Live Server** in Visual Studio Code.
