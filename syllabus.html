COURSE OBJECTIVE

This course enables the students to design and analyze algorithms in terms of efficiency and correctness. The course focuses on highlighting the difference between various problem-solving techniques for efficient algorithm design.

02

Theory Syllabus

I
UNIT I

Recurrences and Asymptotic Notations

Introduction, Algorithm definition, algorithm characteristics, principles of designing algorithms.

Performance Analysis Space Complexity Time Complexity Big-O Notation Omega Notation Theta Notation Amortized Analysis Recurrence Relations Characteristic Equation Generating Functions Master Method Substitution Method
II
UNIT II

Divide and Conquer

Basic strategy and important divide-and-conquer algorithms.

Matrix Operations Strassen's Matrix Multiplication Binary Search Quick Sort Merge Sort Fibonacci Heap Binomial Heap Disjoint Set Representation
III
UNIT III

Greedy Method

Basic strategy and applications of the greedy method.

Fractional Knapsack Problem Job Sequencing with Deadlines Minimum Cost Spanning Trees Prim's Algorithm Kruskal's Algorithm Dijkstra's Algorithm Optimal Search Patterns Activity Selection Problem
IV
UNIT IV

Dynamic Programming

Basic strategy and dynamic programming approaches.

Multistage Graphs All Pairs Shortest Path Floyd Warshall Algorithm Single Source Shortest Paths Bellman Ford Algorithm Optimal Binary Search Trees Travelling Salesman Problem Longest Common Subsequence Chained Matrix Multiplication
V
UNIT V

Basic Traversal

Backtracking, graph problems, and NP-Completeness.

Backtracking 8-Queens Problem Graph Coloring Hamiltonian Cycles Branch & Bound NP-Completeness Non-deterministic Algorithms NP P NP-Hard NP-Complete
VI
UNIT VI

Analysis of Search Algorithms

Types of search problems and algorithms.

Uninformed Search Breadth First Search Depth First Search Uniform Cost Search Informed Search A* Search Iterative Deepening A*

03

Course Outcomes

CO1

Understand

Understand algorithm analysis, design paradigms, and non-deterministic algorithms, and classify problems into P, NP, NP-Hard, and NP-Complete.

CO2

Apply

Utilize algorithmic design paradigms to develop efficient solutions for real-world application problems.

CO3

Evaluate

Estimate the efficiency and effectiveness of algorithms by analyzing their performance and comparing them with alternative solutions.

CO4

Create

Design efficient algorithms to address moderately complex computational problems by effectively applying various algorithmic design paradigms.
